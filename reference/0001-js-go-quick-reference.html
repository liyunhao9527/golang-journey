工具链

做的事JS/TSGo
运行脚本node hello.jsgo run hello.go

格式化prettier --writego fmt

入门语法

主题JS/TSGo
打印一行console.log("x")fmt.Println("x")
注释// 与 /* */相同;文档注释惯例:直接写在声明上方
入口隐式(脚本顶层)func main(),必须在 package main 里
字符串'' "" ``只有 "" 与 ``;'a' 是 rune(字符),不是字符串!
语句结尾分号可选自动插入分号,惯例不写 ;
导出/可见性export 关键字标识符首字母大写 = 导出(跨包可见),小写 = 包内私有
包/模块import ... from "..."import "fmt" —— 按包导入,不写函数名

本课重点记忆:'a' 在 Go 里不是字符串——这是前端开发者最常踩的第一个坑,第 2 课讲类型时会展开。

对照代码:Hello World 双版本

Go — hello.go

package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}
相同点两个版本都会打印同一行文本 不同点Go 使用 package main 和 main 函数，TypeScript 直接执行顶层代码

TypeScript — hello.ts

// 入口是隐式的,顶层代码直接执行
console.log("Hello, Go!");
