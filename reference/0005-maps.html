速查 05 / 复合类型

map 速查

最常用操作

以下是语法示意，不可直接运行；m 为 map[string]int，key 为 string，value 为 int。完整程序见第五课。

m := make(map[string]int) // 创建可写 map
m[key] = value           // 新增或更新
value, ok := m[key]       // 读取与存在性
delete(m, key)           // 删除，无返回值
len(m)                   // 条目数

缺失键返回值类型零值，且不插入条目。nil map 可读不可写。map 赋值共享条目。range 顺序未指定。键必须支持比较，不能是 slice 或 map。

TS 对照：new Map / set / get + has / delete / size。TS get 缺失返回 undefined；Map 按插入顺序遍历。
