声明、创建与区间

语法示意，不可直接运行：下面每行独立展示一种形式；放进 main 时请实际使用声明的变量。完整程序见第四课：数组。

array := [3]int{1, 2, 3}       // 数组，类型是 [3]int
inferred := [...]int{1, 2, 3} // 编译器推断数组长度为 3
slice := []int{1, 2, 3}       // slice，类型是 []int

empty := make([]int, 0, 8)    // len=0, cap=8
ready := make([]int, 3)       // len=3, cap=3，元素均为 0

view := slice[1:3]            // 包含索引 1，不包含索引 3
prefix := slice[:2]
suffix := slice[1:]

view、prefix 与 suffix 都访问 slice 的底层数组，修改重叠元素会彼此可见。

相同点：索引从 0 开始，区间都采用“起点包含、终点不包含”。

不同点：Go 的切片表达式创建共享底层数组的视图；TypeScript 的 Array.prototype.slice 创建新数组并浅复制所选元素。

len、cap 与 append

下面是 main 函数体内的局部片段：

s := make([]string, 0, 3)
s = append(s, "Go")
s = append(s, "并发", "HTTP")

fmt.Println(len(s)) // 3：当前可见元素数
fmt.Println(cap(s)) // 至少 3：当前可延展容量
  • 始终接住 append 返回值。
  • 容量足够时可能复用底层数组；不足时分配新数组。
  • 不要依赖具体扩容倍数；语言规范不保证固定倍率。
  • 追加另一个 slice：dst = append(dst, src...)。

独立浅副本

下面是 main 函数体内的局部片段：

original := []int{1, 2, 3}
cloned := make([]int, len(original))
n := copy(cloned, original)

fmt.Println(n) // 3
cloned[0] = 99 // original[0] 仍是 1

copy(dst, src) 返回 min(len(dst), len(src))。这是浅复制：如果元素内部仍有 slice、map 或其他共享数据，内部存储不会递归复制。

前端最容易踩的 5 个坑

  1. 把 [3]int 当成可增长数组；它的长度属于类型。
  2. 以为 s[1:3] 像 TypeScript 的 slice() 一样复制元素；Go 默认共享存储。
  3. 不接住 append 返回值；这会产生编译错误。
  4. 用 make([]int, 3) 预留容量后又 append 三个值；结果前面先有三个零值。只预留容量应写 make([]int, 0, 3)。
  5. 写 cloned := original 期待独立副本；这只复制 slice 描述符。
