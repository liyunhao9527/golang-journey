速查 06 / 类型与存储

指针速查

读取与修改

下面是 main 函数体内的局部片段；可替换第六课首个完整 Go 程序的函数体，保留 fmt 导入。运行输出 8。

x := 1
p := &x       // p 的类型为 *int
q := p        // 复制指针值，都指向 x
*q = 8        // 修改 x
fmt.Println(x)

p = &y 改变 p 的指向；*p = 8 修改指向的变量。这两种赋值不要混淆。

零值与 TS 对照

var p *int 得到 nil；检查 p != nil 后才解引用。指向 0 的指针不等于 nil。普通 Go 指针不支持指针算术。

TS 没有对已有局部数值变量取地址的运算符。对象属性能承载共享修改，但包装时复制数值，不会与原数值变量建立指针关系。
