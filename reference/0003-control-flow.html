if 多个条件与短路求值

用途Go / TypeScript 表达式
两个条件都成立age >= 18 && hasTicket
至少一个条件成立hasTicket || isMember
取反!isBanned
组合条件(hasTicket || isMember) && !isBanned

相同点：优先级为 ! > && > ||；先计算左边，&& 左边为假、|| 左边为真时跳过右边。

不同点：Go 的条件和逻辑操作数必须是布尔值，不能写 if name {}，要写 if name != "" {}。JS/TS 可做真值判断，且 &&、|| 返回其中一个操作数。

下面是函数体内的片段：:= 和 if 不能直接写在包级作用域。包级变量声明使用 var。

divisor := 0
if divisor != 0 && 10/divisor > 1 {
  fmt.Println("商大于 1")
} else {
  fmt.Println("除数为 0 或商不大于 1")
}

先检查除数，短路跳过整数除零。完整对照与分组练习见第三课：多个条件。

if 带初始化:作用域最小化

// val 只在 if/else 块内可见,出块即消失
if val := len("Go"); val > 100 {
  fmt.Println(val)
} else {
  fmt.Println(val * 2) // else 里也能用
}
// val 在这里不存在(编译错误)

for 的三种形态 + range

以下为语法示意，不可直接运行：n 是计数变量，slice 和 map 代表待遍历的集合；实际循环需要更新条件并使用所声明的变量，见课程完整示例。

for i := 0; i < 5; i++ {}  // 三段式
for n < 100 {}            // = while
for {}                    // = while(true)

for i, v := range slice {}   // 索引 + 值
for _, v := range slice {}   // 只要值(_ 丢弃)
for i := range slice {}      // 只要索引
for k, v := range map {}     // 键 + 值(顺序未指定,不要依赖)

i++ 注意:只有后置 i++,没有 ++i;且它是语句不是表达式——x := i++ 编译报错。

range 遍历字符串:按 rune,索引按字节

for i, c := range "go语言" { fmt.Println(i, c) }
// 4 次迭代:c 依次是 g、o、语、言(类型 rune)
// i 依次是 0、1、2、5 —— 汉字占 3 字节,索引跳的是字节

switch 三差异

  1. 默认不贯穿:case 匹配后自动 break;要贯穿必须显式写 fallthrough(几乎不用)。
  2. case 可为任意表达式,不必是常量;case "sat", "sun": 多值共一分支。
  3. 无条件 switch(switch {} + case cond:)= 整齐的 if-else 链,Go 招牌写法。
score := 87
grade := ""
switch {                // 无条件:按顺序找第一个为真的 case
case score >= 90:
  grade = "A"
case score >= 80:
  grade = "B"
default:
  grade = "C"
}
fmt.Println(grade)

前端最容易踩的 5 个坑

  1. if (x > 10) 语法合法,但不是惯用写法;通常写 if x > 10。
  2. 手滑写三元 a > b ? a : b → 编译报错,Go 没有。
  3. switch 期待贯穿行为 → 没有;显式写 fallthrough。
  4. range 里保留不需要的 i → "declared and not used",用 _ 丢弃。
  5. 期待 for...in/for...of 语法 → Go 只有 for range;另外 map 遍历顺序未指定且不保证稳定。
