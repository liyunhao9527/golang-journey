声明方式

写法位置TS 对照
var x string = "a"包级 / 函数内let x: string = "a"
var x = "a"包级 / 函数内let x = "a"
x := "a"仅函数内TS 无等价物;= let + 推断
const x = "a"包级 / 函数内const x = "a"

铁律:类型一旦确定不可变;:= 左侧至少要有一个新变量;:= 不能与 const 连用。

const 对照:Go 常量必须在编译期确定,并可保持为未类型化常量;TS const 只禁止重新绑定变量,右侧仍可以是运行时对象或函数结果。

易错点

  • 未使用的局部变量、未使用的 import → 编译错误。declared and not used: x
  • 无隐式类型转换:int → float64 必须写 float64(n);JS 的强制转换在 Go 里不存在。
  • := 只能函数内用;包级只有 var / const。
  • 'a' ≠ 字符串:单引号 = rune,双引号 = string。
  • 变量声明了但没初始化是合法的(得到零值)——和 TS 的 "used before assigned" 完全不同。
