& 取地址，* 读写指向的变量

前置知识只需要第二课的变量与第三课的 if；可以先于 map 练习阅读。你已经知道整数赋值会得到独立的值。现在要做的是：通过另一个变量，明确修改原来的整数。

&score 取得 score 的地址，结果类型是 *int；p := &score 保存这个指针。表达式 *p 表示 p 指向的变量：可读，也可赋值。类型里的 *int 表示“指向 int 的指针”，表达式里的 *p 表示“解引用”。

以下为完整程序：保存为 main.go，在文件所在目录执行 go run main.go。

Go / main.go

package main

import "fmt"

func main() {
  score := 10
  copied := score
  p := &score
  *p = 20
  fmt.Println(score, copied, *p)
  fmt.Printf("%T\n", p)
}
相同点整数赋值复制数值；两种语言都可以显式安排共享可修改的数据。不同点Go 可以取已有整数变量的地址；TS 没有这个操作，示例改用对象属性承载共享值。

TypeScript / main.ts（完整脚本）

let score = 10;
let copied = score;
const box = { value: score };
const alias = box;
alias.value = 20;
console.log(score, copied, box.value);

Go 输出：

20 10 20
*int

TypeScript 保存为 main.ts，在所在目录用 Node 24 执行 node main.ts，输出 10 10 20。box.value 最初复制了 score 的数值，修改对象属性不会修改原 score 变量。因此这个对象只是共享修改的对照，不是 Go 取地址的等价翻译。

fmt.Printf("%T\n", p) 打印类型；\n 是换行。依据：Go 规范：地址运算符。

修改 *p 与重新赋值 p 是两件事

*p = 99 修改指向的值；p = &right 改变 p 指向谁。q := p 复制指针值：最初指向同一个变量，之后重新赋值 p 不会同时改变 q。

以下为完整程序：保存为 main.go，在文件所在目录执行 go run main.go。

package main

import "fmt"

func main() {
  left, right := 10, 90
  p := &left
  q := p
  *q = 11
  p = &right
  *p = 99
  fmt.Println(left, right, *q, *p)
  fmt.Println(q == &left, p == &right)
}

先预测，再展开输出。TS 对象引用也有类似区别：修改对象属性会被别名看见，重新绑定某个变量不会重新绑定另一个变量；上节的 box/alias 对照可帮助记忆。

查看输出与解释
11 99 11 99
true true

先执行 *q = 11，left 变成 11。再执行 p = &right，只改变 p 的指向，q 仍指向 left。最后执行 *p = 99，改的是 right。因此 left、right 分别是 11、99。对这些 int 变量，指针相等比较可以确认是否指向同一变量。

普通 Go 指针不支持通过加减整数来移动地址；本课始终通过变量地址建立指向关系。参见官方 Tour：Pointers。

nil 指针：没有指向变量，不能解引用

var p *int 的零值是 nil。它与“指向一个值为 0 的 int”不同。类似 TS 中区分 null 与 { value: 0 }，是否存在与内部数值要分开判断。

以下为完整程序：保存为 main.go，在文件所在目录执行 go run main.go。

package main

import "fmt"

func main() {
  var p *int
  fmt.Println(p == nil)
  if p == nil {
    fmt.Println("not set")
  }
  score := 0
  p = &score
  fmt.Println(p == nil, *p)
}

输出：

true
not set
false 0

先用 p == nil 判断；只有指向有效变量时才能读取或写入 *p。

边界验证：nil 解引用会发生什么？

下面是完整的预期运行错误程序。保存到临时文件 nil.go，在该文件目录执行 go run nil.go。它能编译，但运行时因 nil 指针解引用而 panic。

package main

import "fmt"

func main() {
  var p *int
  fmt.Println(*p)
}

恢复步骤：把 var p *int 替换为两行 score := 0、p := &score，再运行输出 0。也可以先用 if 检查 nil，未设置时不解引用。

特别留意与第五课的差别：nil map 可以查键并返回零值；nil 指针不能解引用。依据：指针类型及解引用规则。

动手练习：让两个指针分开修改

在 demos/06-pointers/sandbox/score.go 从空文件完成：

  1. 声明 score 为 10、backup 为 50；让 p 指向 score，再把 p 赋给 q。
  2. 只通过 p，让 score 增加 5。
  3. 让 p 改为指向 backup，再通过 p 把 backup 改为 99。
  4. 打印 score、backup、*q、*p。

从仓库根目录运行 go run demos/06-pointers/sandbox/score.go。成功输出：

15 99 15 99
参考答案与关键解释
package main

import "fmt"

func main() {
  score, backup := 10, 50
  p := &score
  q := p
  *p = *p + 5
  p = &backup
  *p = 99
  fmt.Println(score, backup, *q, *p)
}

q 保留了指向 score 的指针值。给 p 重新赋值，只改变 p；通过 *p 赋值，才修改它当前指向的变量。

完整基准示例：pointers.go。从仓库根目录执行 go run demos/06-pointers/pointers.go，输出与第一节相同。明天不看答案再写一次，并解释每一步究竟改了“指针”还是“值”。
