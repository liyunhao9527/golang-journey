键值操作：读到 0，不代表键存在

上一课用 slice 按位置取值；本课用 map 按键取值。map[string]int 的键是字符串，值是整数。先完成读、写、更新和删除，再区分“存了 0”与“没有这个键”。

下面均为完整程序。Go 保存为 main.go，在文件所在目录执行 go run main.go；TypeScript 保存为 main.ts，在同一目录用已安装的 Node 24 执行 node main.ts。

Go / main.go

package main

import "fmt"

func main() {
  scores := map[string]int{"Go": 0}
  scores["TS"] = 2
  scores["TS"]++
  fmt.Println(scores["Go"], scores["Rust"], len(scores))
  value, ok := scores["Go"]
  fmt.Println(value, ok)
  value, ok = scores["Rust"]
  fmt.Println(value, ok)
  delete(scores, "TS")
  fmt.Println(len(scores))
}
相同点相同键再次写入会更新已有值，删除后条目数减少。不同点Go 缺失键返回值类型的零值；TS Map.get 返回 undefined。Go 用第二个结果 ok，TS 用 has 判断存在性。

TypeScript / main.ts

const scores = new Map<string, number>([["Go", 0]]);
scores.set("TS", 2);
scores.set("TS", (scores.get("TS") ?? 0) + 1);
console.log(scores.get("Go"), scores.get("Rust"), scores.size);
console.log(scores.get("Go"), scores.has("Go"));
console.log(scores.get("Rust"), scores.has("Rust"));
scores.delete("TS");
console.log(scores.size);

Go 输出：

0 0 2
0 true
0 false
1

TS 前三行分别为 0 undefined 2、0 true、undefined false，最后一行为 1。?? 0 在左侧为 null 或 undefined 时使用 0。

value, ok := scores[key] 一次声明两个变量；ok 是布尔值，不是错误。读取缺失键不会新增条目。例如 Rust 的读取结果是 0、ok 是 false；Go 虽然也存了 0，但 ok 是 true，说明键确实存在。delete(m, key) 删除缺失键也安全，但与 TS 的 delete 方法不同，它不返回布尔值。参见索引规范和删除规范。

nil map：可读，写之前先初始化

回忆：nil slice 可以接住 append 的结果。map 的规则不同：var counts map[string]int 只得到 nil map；写入前用 make 或 map 字面量创建可写的 map。TypeScript 中 new Map() 已创建可写容器。

完整程序，保存为 main.go，在所在目录运行 go run main.go：

package main

import "fmt"

func main() {
  var counts map[string]int
  fmt.Println(counts == nil, len(counts), counts["Go"])
  delete(counts, "Go")
  counts = make(map[string]int)
  counts["Go"]++
  fmt.Println(counts["Go"])
}

输出：

true 0 0
1

nil map 可读取、求 len、delete 和 range（零次迭代）。直接写入会产生运行时 panic。空字面量 map[string]int{} 与 make 都能创建非 nil 的空 map。参见Map types。

赋值共享条目，遍历顺序未指定

map 赋值不会复制全部条目：通过别名写入同一个 map，原变量能读到修改。这个行为对应 TS 的 const alias = counts 后调用 alias.set。以下完整程序保存为 main.go，在所在目录运行 go run main.go。

package main

import "fmt"

func main() {
  counts := map[string]int{"Go": 1}
  alias := counts
  alias["Go"] = 2
  fmt.Println(counts["Go"])
  for word, count := range counts {
    fmt.Println(word, count)
  }
}

输出两行：2 和 Go 2。这里仅一个键；多个键时，Go 的 range 顺序未指定，也不保证两次遍历相同。TS Map 按插入顺序遍历。需要固定展示顺序时，本课先按一个明确的 slice 依次查键。

键必须支持相等比较。本课使用 string；int 也可以，slice 和 map 不可以。与 TS Map 能把数组对象作为身份键的规则不同。参见键类型要求和range 规范。

  2. 创建可写的 map[string]int，用 range 遍历单词，每遇到一次就累加。缺失键的零值正好是计数起点。
  3. 按 Go、TS、Rust、Java 的顺序输出单词、次数和是否存在，复习上一课的 slice 及第三课的 range。

从仓库根目录运行 go run demos/05-maps/sandbox/count.go。成功条件：

Rust 1 true

参考答案：先尝试，再核对
package main

import "fmt"

func main() {
  words := []string{"Go", "TS", "Go", "Rust", "Go", "TS"}
  counts := make(map[string]int)
  for _, word := range words {
    counts[word]++
  }
  for _, word := range []string{"Go", "TS", "Rust", "Java"} {
    count, ok := counts[word]
    fmt.Println(word, count, ok)
  }
}

counts[word]++ 从零值开始计数；最后遍历的是有序 slice，因此输出顺序固定。Java 的 0 只是读取结果，没有被插入 map。
