第 0 步：确认 Go 已安装

先执行下方 go version；看到版本号就跳过安装。尚未安装且已使用 Homebrew 的 macOS 用户，可以运行下面的命令；其他情况使用本课末尾的官方安装说明：

brew install go

验证安装(对照 node --version):

go version
# 期望输出类似:go version go1.24.x darwin/amd64

第 1 步:第一个 Go 程序

这一对文件已经放在 demos/01-hello/ 里:hello.go 是 Go 版,hello.ts 是 TS 对照版(以后每课都有这样的成对代码)。先看 Go 版:

package main

import "fmt"

func main() {
  fmt.Println("Hello, Go!")
}

逐行解读,每一行都和 TS 对照着看:

Go 代码含义TS 对照
package main 声明这个文件属于 main 包。可执行程序的入口包必须叫 main TS 没有包概念;类比"入口文件"约定,但 Go 是强制的
import "fmt" 引入标准库 fmt(格式化输入输出) import { ... } from "..."——但 Go 按"包"导入,不写具体函数名
func main() 程序入口函数。从 main 包的这个函数开始执行 TS 入口是隐式的(脚本顶层代码);Go 必须有显式的 func main()
fmt.Println("Hello, Go!") 打印一行。自动换行、自动在参数间加空格 console.log——但注意 Println 首字母大写,这是 Go 的"导出"标志

以下命令统一在 golang-journey 仓库根目录执行。运行 Go 示例：

go run demos/01-hello/hello.go
# 输出:Hello, Go!

关键差异:go run 会先编译再运行;go build 通常产出单个可执行文件,运行机器不需要安装 Go。不过二进制必须匹配目标操作系统和 CPU 架构;需要发布到其他平台时,要为对应平台重新构建。运行可执行文件时不需要再调用 go run。

对照代码:同一个程序,两种语言

下面先放 Go，再放 TypeScript，比较两种语言的入口写法：

Go — hello.go

package main

import "fmt"

func main() {
  fmt.Println("Hello, Go!")
}
相同点两个程序都从入口开始执行并打印同一行文本 不同点Go 明确声明包和 main 函数，TypeScript 直接执行顶层代码

TypeScript — hello.ts

// 入口是隐式的,顶层代码直接执行
console.log("Hello, Go!");

两个文件输出相同。以下两条命令都从仓库根目录执行：

# Go:先编译再运行
go run demos/01-hello/hello.go

# TS：Node 执行此处不含类型标注的脚本
node demos/01-hello/hello.ts

本例 Go 从 main 包的 main 函数开始执行，TS 脚本执行顶层语句。两种程序都能打印同一行文字，但程序结构和运行工具不同。

亲手区分 run、build 和格式化

继续在仓库根目录操作。先构建；成功后此命令不打印 Hello，也不运行程序：

go build -o demos/01-hello/hello-demo demos/01-hello/hello.go

macOS / Linux 直接运行生成的文件：

./demos/01-hello/hello-demo

Windows PowerShell 构建时把输出名改为 hello-demo.exe，再运行：

go build -o demos/01-hello/hello-demo.exe demos/01-hello/hello.go
.\demos\01-hello\hello-demo.exe

程序输出 Hello, Go!。修改源码后，直接运行旧文件仍是旧结果；重新 build 才会更新文件。go run 则构建后直接运行临时产物，不会更新这里指定的 hello-demo。

格式化只调整源码排版，不执行程序。本仓库示例按单文件运行，无需先初始化模块：

gofmt -w demos/01-hello/hello.go

go fmt 按包调用 gofmt；处理本课单个文件时，直接用 gofmt 最清楚。测试、依赖和模块命令先作为速查，后续课程再使用。

动手练习

在 demos/01-hello/hello.go 基础上改造(TS 对照文件 hello.ts 保持原样):

  1. 打印 Hello, <你的名字>!
  2. 再打印一行你最喜欢的编程语言。提示:fmt.Println 一次只打印一行,但可以在一个调用里传多个参数:fmt.Println("A", "B") 会输出 A B
go run demos/01-hello/hello.go
参考代码与期望输出(先自己写完再看) 
package main

import "fmt"

func main() {
  fmt.Println("Hello, Leo!")
  fmt.Println("I love TypeScript!")
}
Hello, Leo!
I love TypeScript!

如果输出和预期不一样,先检查:字符串用了双引号?单词大小写?文件名以 .go 结尾?
