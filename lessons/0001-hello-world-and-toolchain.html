第 0 步:安装 Go

如果机器还没装 Go,macOS 可以用 Homebrew 一条命令安装(只运行一次);其他系统使用本课末尾的官方安装说明:

brew install go

验证安装(对照 node --version):

go version
# 期望输出类似:go version go1.24.x darwin/amd64

第 1 步:第一个 Go 程序

这一对文件已经放在 demos/01-hello/ 里:hello.go 是 Go 版,hello.ts 是 TS 对照版(以后每课都有这样的成对代码)。先看 Go 版:

package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}

逐行解读,每一行都和 TS 对照着看:

Go 代码含义TS 对照
package main 声明这个文件属于 main 包。可执行程序的入口包必须叫 main TS 没有包概念;类比"入口文件"约定,但 Go 是强制的
import "fmt" 引入标准库 fmt(格式化输入输出) import { ... } from "..."——但 Go 按"包"导入,不写具体函数名
func main() 程序入口函数。从 main 包的这个函数开始执行 TS 入口是隐式的(脚本顶层代码);Go 必须有显式的 func main()
fmt.Println("Hello, Go!") 打印一行。自动换行、自动在参数间加空格 console.log——但注意 Println 首字母大写,这是 Go 的"导出"标志

运行它(对照 node hello.js):

cd demos/01-hello
go run hello.go
# 输出:Hello, Go!

关键差异:go run 会先编译再运行;go build 通常产出单个可执行文件,运行机器不需要安装 Go。不过二进制必须匹配目标操作系统和 CPU 架构;需要发布到其他平台时,要为对应平台重新构建。这是和 Node 生态最大的心智差异之一。

对照代码:同一个程序,两种语言

上面讲的是"Go 怎么写",现在把两个版本并排放——这是本课程的核心学习方式,每个概念都给你一份可运行的双语对照:

Go — hello.go

package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}
相同点两个程序都从入口开始执行并打印同一行文本 不同点Go 明确声明包和 main 函数，TypeScript 直接执行顶层代码

TypeScript — hello.ts

// 入口是隐式的,顶层代码直接执行
console.log("Hello, Go!");

两个文件输出完全一样,运行方式对照:

# Go:先编译再运行
cd demos/01-hello && go run hello.go

# TS:直接解释执行
cd demos/01-hello && node hello.ts

注意 hello.ts 里没有 package、没有 import、没有 func main()——TS 的入口是隐式的,Go 的一切都是显式的。这就是第一课的对照结论。

第 2 步:工具链对照表

做的事JS/TSGo
运行脚本node hello.jsgo run hello.go
编译 / 类型检查tsc --noEmitgo build
格式化prettier --writego fmt(官方工具,社区铁律)
初始化项目npm initgo mod init <module名>
调整模块依赖版本npm install <pkg>go get <module>@<version>
安装命令行工具npm install -g <pkg>go install <pkg>@<version>
整理依赖清单—(npm 自动写)go mod tidy(显式整理)
跑测试vitest / jestgo test(测试框架是标准库自带)
运行所需Node.js + 应用代码/依赖通常只需目标平台的可执行文件

两个值得记住的要点:

  • go fmt 不是插件:它是官方工具,所有 Go 代码格式统一,团队里不存在"格式之争"。
  • 测试是内置的:不需要选型 vitest 还是 jest——go test 就是标准。

动手练习

在 demos/01-hello/hello.go 基础上改造(TS 对照文件 hello.ts 保持原样):

  1. 打印 Hello, <你的名字>!
  2. 再打印一行你最喜欢的编程语言。提示:fmt.Println 一次只打印一行,但可以在一个调用里传多个参数:fmt.Println("A", "B") 会输出 A B
cd demos/01-hello
go run hello.go
参考代码与期望输出(先自己写完再看)

import "fmt"

func main() {
    fmt.Println("Hello, Leo!")
    fmt.Println("I love TypeScript!")
}
Hello, Leo!
I love TypeScript!

如果输出和预期不一样,先检查:字符串用了双引号?单词大小写?文件名以 .go 结尾?
