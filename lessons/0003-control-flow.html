if：组合条件与作用域

结构上和 TS 几乎一样。Go 的惯用写法是条件不加括号,花括号必须写。就算只有一行也是如此。额外括号在语法上合法,但没有必要;读 Go 代码和写 Go 代码时都应认得这两种形式:

Go

if x > 10 {
  fmt.Println("big")
}
相同点两种语言都用条件分支和块级作用域 不同点Go 的条件通常不加括号，花括号必须写

TypeScript

if (x > 10) {
  console.log("big");
}

多个条件：并且、或者、取反

下面是完整的 Go 程序，可保存为 main.go 后运行 go run main.go。:= 短变量声明和 if 语句必须放在函数体内；包级变量可以用 var 声明，但不能用 :=。TypeScript 对照可以直接写在脚本顶层。

和 JS/TS 一样，&& 表示“两个条件都成立”，|| 表示“至少一个成立”，! 表示“取反”。

Go

package main

import "fmt"

func main() {
  age := 20
  hasTicket := true
  isMember := false
  isBanned := false

  if age >= 18 && hasTicket {
    fmt.Println("成年且有票")
  }
  if hasTicket || isMember {
    fmt.Println("有票或是会员")
  }
  if (hasTicket || isMember) && !isBanned {
    fmt.Println("可以入场")
  }
}
相同点三个逻辑运算符的含义、优先级和短路规则一致 不同点Go 的逻辑运算要求布尔操作数；JS/TS 的 &&、|| 可接受其他类型，并返回其中一个操作数

TypeScript

const age = 20;
const hasTicket = true;
const isMember = false;
const isBanned = false;

if (age >= 18 && hasTicket) {
  console.log("成年且有票");
}
if (hasTicket || isMember) {
  console.log("有票或是会员");
}
if ((hasTicket || isMember) && !isBanned) {
  console.log("可以入场");
}

优先级从高到低是 !、&&、||。a || b && c 相当于 a || (b && c)。上例用 (hasTicket || isMember) && !isBanned 明确要求：有票或是会员，并且未被禁止入场。这里的分组括号决定逻辑，不能随意去掉。

条件必须是布尔值：Go 不能像 JS/TS 那样写 if age {} 或 if name {}，要明确写 if age != 0 {} 或 if name != "" {}。布尔变量可以直接用，例如 if hasTicket {}。

短路求值：先检查，再计算

两个运算符都先计算左边。&& 左边为假时跳过右边；|| 左边为真时跳过右边。可以用它避免无效计算。下面是函数体内的片段，可替换上例 main 函数体中的内容：

divisor := 0
if divisor != 0 && 10/divisor > 1 {
  fmt.Println("商大于 1")
} else {
  fmt.Println("除数为 0 或商不大于 1")
}

divisor != 0 为假，右边的整数除法不会执行，因此不会触发除零 panic。JS/TS 也有同样的短路规则，但普通 number 除零不会像 Go 整数除零那样 panic。

运行 go run demos/03-control-flow/control.go，其中 demoIfConditions 会依次输出“成年且有票”“有票或是会员”“可以入场”“除数为 0 或商不大于 1”。

动手验证：禁止入场时，有票还能通过吗？

在 demoIfConditions 中把 isBanned 改成 true 后运行：前两行仍输出，但不应出现“可以入场”。再去掉条件中的分组括号，观察差异，最后恢复原示例。

参考解释：没有括号时，条件变成 hasTicket || (isMember && !isBanned)。有票就会通过，绕过禁止入场的检查。保留括号才能让 !isBanned 约束两种入场资格。

初始化语句与作用域

  • if 可以带初始化语句,用分号隔开。这是 Go 最重要的惯用法之一:
// 先执行 val := something(),再判断
if val := compute(); val > 100 {
  fmt.Println(val) // ✓ 只在这个 if/else 块里可见
}
// fmt.Println(val) // ✗ 编译错误:val 出了块就不存在

TS 没有 initializer 语法,通常要先声明再判断。let/const 本身是块级作用域,所以可以用额外的块限制变量范围;Go 的优势是把“计算 + 判断 + 作用域”紧凑地写在一条 if 语句中:

{
  const val = compute();
  if (val > 100) {
    console.log(val);
  }
}
// console.log(val); // 编译错误:val 已超出块级作用域
  • 没有三元表达式 cond ? a : b。Go 认为三元可读性差,一律写 if/else。这是前端写 Go 最常"手痒"的地方。

为什么?Go 的口号是"一种事只有一种写法"。while 能写成 for,三元能写成 if,那它们就不该存在。少一种写法,读别人的代码时就少一次猜测。

for：一个关键字，三种循环

Go 里只有 for,没有 while、没有 do-while。但 for 一个关键字覆盖了全部三种循环:

Go / 三种形态

// 1. 经典三段式(没有括号!)
for i := 0; i < 5; i++ {
  fmt.Println(i)
}

// 2. while 型:只留条件
n := 1
for n < 100 {
  n *= 2
}

// 3. 无限循环:什么都不写
for {
  break // 没有 break 就永远跑
}
相同点都能写计数、条件和无限循环 不同点Go 的三种循环全部使用 for

TypeScript / 对应写法

// 1. 经典三段式
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// 2. while
let n = 1;
while (n < 100) {
  n *= 2;
}

// 3. 无限循环
while (true) {
  break;
}

记住一句话:for cond {} 就是 Go 的 while,for {} 就是 Go 的 while (true)。

没有 ++i,只有 i++。而且 i++ 是语句不是表达式,不能写 x := i++,避免了 JS 里 ++i + i++ 这类谜题。

range:遍历的主角

遍历集合不用 for...of,用 for range(slice/map 细节下两课展开,这里先记住形态):

Go

names := []string{"a", "b", "c"}

for i, name := range names {
  fmt.Println(i, name)
}

// 只要值:用 _ 丢弃索引
for _, name := range names {
  fmt.Println(name)
}

// 只要索引
for i := range names {
  fmt.Println(i)
}
相同点两种语言都能逐项遍历集合 不同点Go 的 range 可以同时返回索引和值

TypeScript

const names = ["a", "b", "c"];

names.forEach((name, i) => {
  console.log(i, name);
});

for (const name of names) {
  console.log(name);
}

for (const i in names) {
  console.log(i); // 注意:这是字符串!
}

_(下划线)是 Go 的"我故意不要这个值"。还记得第 2 课吗?未使用的变量是编译错误,所以不想用就必须显式扔掉,而 _ 专门豁免这条规则。

字符串也可以直接用 range 遍历。下面的 c 是 rune(底层类型是 int32),所以中文和 emoji 都会作为一个完整字符取出:

Go

for i, c := range "go语言 🚀" {
  fmt.Printf("字节索引=%d, 字符=%c, 类型=%T\n", i, c, c)
}
// 输出的索引大致是:0 1 2 5 8 9
// g  o  语   言  空格 🚀
相同点两种写法都按 Unicode 码点遍历 不同点Go 还会同时得到 UTF-8 字节索引

TypeScript

for (const c of "go语言 🚀") {
  console.log("字符=", c);
}
// for...of 也会逐个取出 Unicode 码点,
// 但它不会同时给出 Go 那样的字节索引。

关键差异:Go 的 range 按 rune(Unicode 码点)迭代,同时返回 UTF-8 字节索引。JS/TS 的 for...of 也按 Unicode 码点迭代,不会拆开这里的 emoji,但没有同时提供字节索引;传统字符串索引 s[i] 才会暴露 UTF-16 码元。

switch：默认不贯穿，也可以没有条件

这是 Go 和 TS 差异最大的控制流。三个差异,个个都是反转:

1. 默认不 fallthrough。TS 的 switch 不写 break 会贯穿到下一个 case(JS 经典 bug 源);Go 反过来:每个 case 自动 break,想贯穿反而要显式写 fallthrough:

Go

switch day {
case "sat", "sun": // 多值共用一个 case
  fmt.Println("周末")
case "mon":
  fmt.Println("周一")
  // 自动 break,不会贯穿!
}
相同点两种语言都用 case 选择分支 不同点Go 的分支默认结束，不需要写 break

TypeScript

switch (day) {
  case "sat":
  case "sun": // 要这样手动堆
    console.log("周末");
    break; // 忘了就贯穿,经典 bug
  case "mon":
    console.log("周一");
    break;
}

2. case 不要求是常量。可以写任意表达式,所以 switch 能当"更整齐的 if-else 链"用。无条件 switch 是 Go 的招牌惯用法:

score := 87
switch {
case score >= 90:
  grade = "A"
case score >= 80:
  grade = "B"
default:
  grade = "C"
}

3. switch 也能带初始化语句,和 if 一样用分号:

switch v := compute(); {
case v > 100:
  ...
}

动手练习

完整可运行代码在 demos/03-control-flow/(control.go / control.ts),覆盖 if 组合条件与短路求值、三种 for、range 和 switch 写法。

  1. 运行 go run control.go,对照注释确认每段输出。
  2. 区分“合法”与“惯用”:(a) 把 if x > 10 写成 if (x > 10) 并运行,确认它语法合法,然后恢复为惯用写法;(b) 在 range 循环里保留 i 但不使用它,亲手触发未使用变量的编译错误,再用 _ 修复。
  3. 用无条件 switch 写一个 FizzBuzz(1-15):能被 3 整除打印 Fizz,被 5 整除打印 Buzz,同时整除打印 FizzBuzz。这是本课的实战胜利。
  4. 猜一下再验证:for i, c := range "go语言" 里,循环跑几次、c是什么类型?(提示:range 字符串按 rune 走)
第 2、3 步参考答案(先自己完成再看)

第 2 步:if (x > 10) 能编译,但 Go 代码通常省略这层括号。range 中声明了索引却不用会报 declared and not used: i;改为 for _, value := range values。

FizzBuzz 参考实现:

for i := 1; i <= 15; i++ {
  switch {
  case i%15 == 0:
    fmt.Println("FizzBuzz")
  case i%3 == 0:
    fmt.Println("Fizz")
  case i%5 == 0:
    fmt.Println("Buzz")
  default:
    fmt.Println(i)
  }
}

同时整除的分支要放在最前面;否则 15 会先命中 i%3 == 0。

第 4 步期望输出(先猜完再看) 
循环 4 次;c 是 rune(int32)
i 的值:0 1 2 5("语"和"言"各占 3 个字节,索引按字节推进:语从 2 开始,言从 5 开始)

range 字符串返回"字节索引 + rune"。索引跳字节、值是码点。这是 Go 处理 Unicode 比 JS 干净的地方,也是最容易惊讶的地方。

阶段复习：从空文件独立写

新建一个 review.go,不要复制现有 demo。用前三课的知识完成下面任务:

  1. 声明常量 limit = 10,再声明一个零值为 0 的整数 sum。
  2. 用三段式 for 遍历 1 到 limit。
  3. 用无条件 switch 打印每个数是“奇数”还是“偶数”,并把偶数累加到 sum。
  4. 循环结束后打印 偶数之和: 30。
阶段复习参考代码(独立写完再看) 
package main

import "fmt"

func main() {
  const limit = 10
  var sum int

  for i := 1; i <= limit; i++ {
    switch {
    case i%2 == 0:
      fmt.Println(i, "偶数")
      sum += i
    default:
      fmt.Println(i, "奇数")
    }
  }

  fmt.Println("偶数之和:", sum)
}
