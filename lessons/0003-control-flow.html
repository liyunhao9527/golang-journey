Lesson 03 · 语法基础

控制流:没有 while 的 for,不会贯穿的 switch

预计 15 分钟 · 对照基线:TypeScript · 主源:A Tour of Go — For

本课胜利:能用 for 写出所有三种循环(包括 while 型和无限循环),能用带初始化语句的 if 和 switch 收窄变量作用域——并理解为什么 Go 敢删掉 while 和三元表达式。

if:长得像,但有两个 Go 味

结构上和 TS 几乎一样,只有一处强制差异:条件不需要(也不允许)括号,但花括号必须写——就算只有一行:

Go

if x > 10 {
    fmt.Println("big")
}

TypeScript

if (x > 10) {
  console.log("big");
}

两个 Go 独有的味道:

  • if 可以带初始化语句,用分号隔开。这是 Go 最重要的惯用法之一:
// 先执行 val := something(),再判断
if val := compute(); val > 100 {
    fmt.Println(val) // ✓ 只在这个 if/else 块里可见
}
// fmt.Println(val) // ✗ 编译错误:val 出了块就不存在

TS 没有这个语法,等价写法是把声明放在外面——于是变量泄漏到整个函数作用域。Go 用这个设计鼓励你把变量的生命周期压到最小。

  • 没有三元表达式 cond ? a : b。Go 认为三元可读性差,一律写 if/else。这是前端写 Go 最常"手痒"的地方。

为什么?Go 的口号是"一种事只有一种写法"。while 能写成 for,三元能写成 if,那它们就不该存在。少一种写法,读别人的代码时就少一次猜测。

for:唯一的循环,三种形态

Go 里只有 for,没有 while、没有 do-while。但 for 一个关键字覆盖了全部三种循环:

Go — 三种形态

// 1. 经典三段式(没有括号!)
for i := 0; i < 5; i++ {
    fmt.Println(i)
}

// 2. while 型:只留条件
n := 1
for n < 100 {
    n *= 2
}

// 3. 无限循环:什么都不写
for {
    break // 没有 break 就永远跑
}

TypeScript — 对应写法

// 1. 经典三段式
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// 2. while
let n = 1;
while (n < 100) {
  n *= 2;
}

// 3. 无限循环
while (true) {
  break;
}

记住一句话:for cond {} 就是 Go 的 while,for {} 就是 Go 的 while (true)。

没有 ++i,只有 i++——而且 i++ 是语句不是表达式,不能写 x := i++,避免了 JS 里 ++i + i++ 这类谜题。

range:遍历的主角

遍历集合不用 for...of,用 for range(slice/map 细节下两课展开,这里先记住形态):

Go

names := []string{"a", "b", "c"}

for i, name := range names {
    fmt.Println(i, name)
}

// 只要值:用 _ 丢弃索引
for _, name := range names {
    fmt.Println(name)
}

// 只要索引
for i := range names {
    fmt.Println(i)
}

TypeScript

const names = ["a", "b", "c"];

names.forEach((name, i) => {
  console.log(i, name);
});

for (const name of names) {
  console.log(name);
}

for (const i in names) {
  console.log(i); // 注意:这是字符串!
}

_(下划线)是 Go 的"我故意不要这个值"——还记得第 2 课吗?未使用的变量是编译错误,所以不想用就必须显式扔掉,而 _ 专门豁免这条规则。

字符串也可以直接用 range 遍历。下面的 c 是 rune(底层类型是 int32),所以中文和 emoji 都会作为一个完整字符取出:

Go

for i, c := range "go语言 🚀" {
    fmt.Printf("字节索引=%d, 字符=%c, 类型=%T\n", i, c, c)
}
// 输出的索引大致是:0 1 2 5 8 9
// g  o  语   言  空格 🚀

TypeScript

for (const c of "go语言 🚀") {
  console.log("字符=", c);
}
// for...of 也会逐个取出 Unicode 码点,
// 但它不会同时给出 Go 那样的字节索引。

关键差异:range 遍历字符串时按 rune(Unicode 码点)走,不是按字节也不是按 JS 那样的 UTF-16 码元。遇到 emoji 也不会像 JS 那样拆成两个代理项。这对前端是好消息。

switch:默认不贯穿,还能没有条件

这是 Go 和 TS 差异最大的控制流。三个差异,个个都是反转:

1. 默认不 fallthrough。TS 的 switch 不写 break 会贯穿到下一个 case(JS 经典 bug 源);Go 反过来——每个 case 自动 break,想贯穿反而要显式写 fallthrough:

Go

switch day {
case "sat", "sun": // 多值共用一个 case
    fmt.Println("周末")
case "mon":
    fmt.Println("周一")
    // 自动 break,不会贯穿!
}

TypeScript

switch (day) {
  case "sat":
  case "sun": // 要这样手动堆
    console.log("周末");
    break; // 忘了就贯穿,经典 bug
  case "mon":
    console.log("周一");
    break;
}

2. case 不要求是常量。可以写任意表达式,所以 switch 能当"更整齐的 if-else 链"用——无条件 switch 是 Go 的招牌惯用法:

score := 87
switch {
case score >= 90:
    grade = "A"
case score >= 80:
    grade = "B"
default:
    grade = "C"
}

3. switch 也能带初始化语句,和 if 一样用分号:

switch v := compute(); {
case v > 100:
    ...
}
