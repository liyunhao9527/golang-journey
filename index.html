学习路线

每个阶段，都有可验证的结果

按练习表现推进。后续主题会拆成短课，不预设完成周数。
  1. 01

    程序与基础语法

    工具链、变量与类型、控制流；第 1–3 课已开放。

    过关证据从空目录运行程序，独立完成条件判断和循环统计。

  2. 02

    数据与值的传递

    数组、slice、map、指针；第 4–6 课已开放。后续补充字符串、rune 与函数。

    过关证据预测复制和共享后的修改结果，区分缺失键与零值，安全处理 nil。

  3. 03

    类型、组合与错误

    计划：struct、方法、接口、显式 error、defer、包与 module、表驱动测试、泛型入门。

    过关证据将统计逻辑拆成可测试的包，通过接口替换依赖，并覆盖失败分支。

  4. 04

    并发与取消

    计划：goroutine、channel、select、sync、context；对照 Promise 与事件循环。

    过关证据实现有并发上限且可取消的任务，解释关闭责任，通过竞态检测。

  5. 05

    标准库与工程实践

    计划：文件与 io、JSON、net/http、配置、日志、构建；按兴趣阅读开源项目。

    过关证据交付可运行的 CLI 或 HTTP 服务，提供边界测试、启动说明与验收命令。

完整教学安排与复习方式

工程实践 / 计划中

把练习连接成完整作品

先系统学习，再按兴趣选择项目。以下是实践安排，尚未提供项目教程。

命令行工具

目录统计 CLI

遍历目录，按扩展名统计文件数量与大小，支持忽略目录和 JSON 输出。

阶段 5 学完文件 I/O 后开始。验收：空目录、无效路径与权限错误测试，退出码和构建说明。

HTTP 服务

学习书签 API

用 net/http 实现书签增删改查、JSON 校验和统一错误响应，再加入持久化。

阶段 5 学完 HTTP 后开始。验收：httptest 接口测试、非法输入、重启后数据保留和 curl 示例。

并发实践

站点可用性检查器

并发检查一组 URL，限制并发数，支持超时与取消，汇总每个地址的结果。

阶段 4 与 HTTP 客户端基础完成后开始。验收：本地测试服务器覆盖成功、失败、超时与取消，通过竞态检测。
