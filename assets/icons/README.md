# IconPark assets

Source: [ByteDance IconPark](https://github.com/bytedance/IconPark), package `@icon-park/svg@1.4.2`.

This directory vendors a deliberately small outline-style SVG sprite for the static course pages. The paths come from the official package and use IconPark's 48 by 48 view box. Colors are normalized to `currentColor` so the icons follow the site's light and dark themes.
